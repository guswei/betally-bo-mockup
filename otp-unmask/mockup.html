後端紅線（前端擋不算數）
  • 列表 API 的回應不得包含明碼，不論操作者權限。否則開發者工具就能繞過遮罩。
  • 解遮罩走獨立 endpoint POST /otp-report/{id}/reveal，回單筆明碼。用 POST 不用 GET：要寫審計，且不該被快取或讓 id 出現在存取 log 的 URL。
  • 後端一律重驗：權限 → 403；OTP 仍有效 → 409 OTP_STILL_VALID；非 FORGET_PASSWORD → 409 OTP_PROCESS_NOT_ELIGIBLE；不存在 → 404。
